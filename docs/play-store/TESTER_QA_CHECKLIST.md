# 32 Visualisations Tester QA Checklist

Thank you for testing **32 Visualisations**. This should take about **30 minutes**.

This is not meant to feel like formal corporate QA. The aim is to play some music, enjoy the visualisations, and tell us whether the app feels smooth, clear, and trustworthy.

## Before You Start

You will need:

- An Android phone.
- The Google Play test link.
- A few local audio files on your phone. Supported formats include `.wav`, `.mp3`, `.m4a`, `.aac`, `.flac`, `.ogg`, and `.opus`.
- Headphones, Bluetooth speaker, car stereo, or any setup that lets you enjoy the music.

Please note your phone model and Android version if you know them.

## 1. Install And First Launch - 3 Minutes

1. Open the Google Play test link.
2. Opt in as a tester.
3. Install **32 Visualisations** from Google Play.
4. Launch the app.

Check:

- Did installation work normally?
- Did the app open cleanly?
- Did the first screen make sense?
- Did anything feel alarming, confusing, or broken?

## 2. Choose Music Folder - 4 Minutes

1. Tap the folder/directory control.
2. Choose a folder containing local audio files.
3. Confirm that the app finds your music.

Check:

- Was it obvious how to choose music?
- Did Android ask for permission in a way that made sense?
- Did your tracks appear?
- If no tracks appeared, what folder/file type did you try?

## 3. Basic Playback - 5 Minutes

Play at least two tracks.

Try:

- Play/pause.
- Next track.
- Previous track.
- Let one track play for a minute or two.

Check:

- Did playback start quickly?
- Did the title/progress display make sense?
- Did the app keep playing reliably?
- Did the controls feel large and clear enough?

## 4. Visualisation Tour - 8 Minutes

Now enjoy yourself a bit.

While music is playing:

1. Press visualisation next several times.
2. Press visualisation previous several times.
3. Let a few visualisations run for 20-30 seconds each.
4. Try at least one fast/loud track if you have one.
5. Try one quieter or gentler track if you have one.

Check:

- Which visualisation did you like most?
- Did any visualisation feel too chaotic, too fast, or hard to look at?
- Did the visualisation changes happen smoothly?
- Did the app ever freeze, stutter badly, or crash?

## 5. Car-Style Controls - 5 Minutes

Try the main cockpit controls:

- Shuffle on/off.
- `Alchemy` for alchemical adjustment.
- `Speed` for visual intensity.
- Play/pause again.
- Next/previous track again.

Check:

- Did `Alchemy` visibly change the mood/settings?
- Did `Speed` make the visualisations feel more or less intense?
- Did the gold/flame button feedback feel satisfying and clear?
- Could you imagine using these controls without staring at them for too long?

## 6. Real-World Behaviour - 3 Minutes

Try one or two of these if convenient:

- Lock the phone, then return to the app.
- Switch to another app, then return.
- Rotate the phone.
- Connect/disconnect Bluetooth.
- Pause for a moment, then resume.

Check:

- Did playback continue or recover in a sensible way?
- Did the app return to the same track/settings?
- Did anything unexpected happen?

## Useful Feedback Examples

Short comments are fine:

- "Installed fine and played three local audio files."
- "Folder selection was confusing on my phone."
- "Alchemy was fun and changed the visual settings noticeably."
- "Speed made the visuals much livelier."
- "The button flash felt great."
- "It crashed when I skipped tracks quickly."
- "I would happily use this in the car."

## Testing Period

Google's test process may require the app to remain in testing for **14 continuous days**.

That does not mean you need to test heavily for 14 days. A few short uses during the period are enough. The most important thing is that you opt in, install the app, try it honestly, and report anything strange.
