# 32 Visualisations Sample Suite

These three original WAV files are bundled as the default sample suite for 32 Visualisations:

- `Attend Your Being.wav`
- `Fit for Public Circulation.wav`
- `Ugly Emu Girls.wav`

They are included so the desktop and Android player have a small, immediate library to demonstrate the visualisations. The app is still primarily designed to play the user's own local music folder.
