# 32 Visualisations Sample Suite

These three original WAV files are optional repository samples for 32 Visualisations:

- `Attend Your Being.wav`
- `Fit for Public Circulation.wav`
- `Ugly Emu Girls.wav`

They are kept in GitHub so people can try the desktop/server workflow without first choosing a music library. They are not packaged inside the Android app. The Android player is deliberately lean and expects the user's own local music folder.
